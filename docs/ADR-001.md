# ADR 001 — One deployable local demo

**Status:** Accepted for demo delivery, 2026-10-28.

The brief describes an advanced microservice target. An empty project needed to become a dependable, demonstrable full-stack application with minimal local setup. The local environment has Java and Node, but no Docker or global Maven.

We use one Spring Boot application and one React frontend, packaged in one executable jar. The backend keeps authentication, ticket/onboarding business rules, scheduled SLA checks, and persistence on the server. An embedded H2 database in MySQL compatibility mode provides durable local data; Flyway and the optional MySQL profile prepare a container-based path without requiring it for the presentation.

This choice makes startup and the main user journey reliable while retaining meaningful authorization and transactional checks. It also keeps a clear boundary between working demo capabilities and infrastructure that has not been connected.

Tradeoffs: this deployment is not independently scaled microservices, does not implement service-owned schemas or an event broker, uses local sessions instead of OIDC, and computes analytics over a bounded demo dataset. A production iteration should add OIDC, a durable outbox and delivery workers, private object storage, database-backed idempotency/reference allocation, server-side SQL aggregations/pagination for large datasets, and configured support-team partitions before separating services.
